# 🎬 Анализ тональности отзывов с Кинопоиска

## 📊 Данные
- **Источник:** Кинопоиск (датасет Михаила Клемина)
- **Количество:** 131,573 отзывов
- **Классы:** Bad (15%), Neutral (19%), Good (66%)

## ⚙️ Методология
1. **EDA:** Анализ распределения, длины отзывов, частоты слов
2. **Предобработка:** Лемматизация (pymorphy3), удаление стоп-слов
3. **Векторизация:** Tf-IDF (30k признаков, ngram=(1,2))
4. **Модели:** LogisticRegression, LinearSVC, MultinomialNB
5. **Подбор гиперпараметров:** GridSearchCV (3-fold)

## 📈 Результаты
| Модель | Accuracy | F1-macro |
|--------|----------|----------|
| LinearSVC | **76.89%** | **0.652** |
| LogisticRegression | 72.52% | 0.648 |
| MultinomialNB | 73.81% | 0.530 |

## 🔬 Анализ ошибок
- Худший класс: Neutral (F1=0.40)
- Лучший класс: Good (F1=0.88)
- Основная проблема: дисбаланс классов
